# Emergency Threshold Flags

When any marker crosses these thresholds:
1. Halt all protocol recommendations
2. Issue CLINICAL ESCALATION NOTICE first
3. Specify marker, client value, threshold breached
4. Direct coach to refer client to medical care

## CARDIAC / VASCULAR
| Marker | Threshold | Concern |
|---|---|---|
| Hs-CRP | >10 mg/L | Active inflammation / cardiac risk |
| Hematocrit | >54% M / >50% F | Polycythemia / thrombosis risk |
| Hemoglobin | >18.5 g/dL | Hyperviscosity syndrome |
| ApoB+CRP | ApoB>160 + CRP>3 | Compounding atherogenic risk |

## HEPATIC
| Marker | Threshold | Concern |
|---|---|---|
| ALT | >120 U/L (3x ULN) | Drug-induced liver injury |
| AST | >120 U/L (3x ULN) | Hepatocellular damage |
| GGT | >180 U/L sustained | Biliary obstruction |

## RENAL
| Marker | Threshold | Concern |
|---|---|---|
| eGFR | <45 mL/min | Stage 3B CKD |
| Creatinine | >1.9 mg/dL | Renal insufficiency |

## ENDOCRINE
| Marker | Threshold | Concern |
|---|---|---|
| LH+FSH | Both <1.0 mIU/mL | Profound HPTA suppression |
| Prolactin | >25 ng/mL | Rule out pituitary adenoma |
| Glucose | >200 mg/dL fasting | Uncontrolled diabetes |
| HbA1c | >8.0% | Poorly controlled glycemia |

## ELECTROLYTES
| Marker | Threshold | Concern |
|---|---|---|
| Potassium | <3.0 or >6.0 mEq/L | Cardiac arrhythmia risk |
| Sodium | <125 mEq/L | Neurological emergency |
| Ferritin | <12 ng/mL | Iron deficiency anemia |
